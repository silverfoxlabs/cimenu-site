CIMenu Support

The fastest path from build failure to error — without opening Xcode.

CIMenu is a native macOS menu bar app that monitors Xcode Cloud builds via the App Store Connect API. It surfaces build status, history, and on-device AI failure analysis from your menu bar, so you don't have to navigate Xcode or App Store Connect's web UI to find out what broke.

FAQ

Does CIMenu require Xcode Cloud?
Yes. CIMenu connects to the App Store Connect API and currently supports Xcode Cloud only.
What do I need to connect my account?
An App Store Connect API key (Issuer ID, Key ID, and a .p8 private key) for at least one Xcode Cloud project. You can generate one in App Store Connect under Users and Access → Integrations.
What data does CIMenu access, and where does it go?
See the Privacy Policy for the full breakdown — in short, your API key stays in the macOS Keychain and never leaves your Mac.
What are the system requirements?
macOS 26 (Tahoe) or later, on Apple Silicon.
I don't have an Xcode Cloud project — can I still try CIMenu?
Yes — enable Demo Mode from Settings → General → Developer, then quit and relaunch the app. It populates CIMenu with scripted sample build data instead of a real account.
